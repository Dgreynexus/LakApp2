# Libas National High School Student Handbook PWA V2

Version 2 adds:
- Student Hub dashboard
- Emergency information card saved locally on the device
- Parent/student acknowledgement helper
- 10-question handbook knowledge check
- Searchable handbook
- Chapter navigation
- Dark mode
- Print mode
- Installable PWA
- Offline caching

The handbook's substantive text is based on the supplied DOCX. Added features are presentation/utility features and do not replace school policy.

Deploy the folder over HTTPS (or localhost) to enable full PWA installation/service-worker behavior.
